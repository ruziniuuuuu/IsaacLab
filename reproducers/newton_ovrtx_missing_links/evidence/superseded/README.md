# Superseded evidence

These files are the first capture published with the reproducer. They are kept
only to document a detector mistake: `rgb_env_0_reference.png` was treated as a
good reference, but visual inspection showed that it was also missing geometry.
The silhouette-only, environment-zero-relative detector could not see common-mode
or interior link loss. Do not use these images as the expected rendering.

The corrected CPU-versus-GPU evidence is in the parent directory.
